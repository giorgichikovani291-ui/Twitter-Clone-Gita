# Twitter/X კლონი

სრულფასოვანი Twitter/X-ის მსგავსი აპლიკაცია — Next.js, SQLite მონაცემთა ბაზა, საკუთარი ავთენტიფიკაცია.

## გაშვება

```bash
npm install
npm run dev
```

გახსენით `http://localhost:3000`. მონაცემთა ბაზა (`data/app.db`) ავტომატურად შეიქმნება პირველივე გაშვებისას, 18 დემო-მომხმარებლითა და ათობით პოსტით/პასუხით/ციტატით.

**დემო ანგარიში:**
- მომხმარებელი: `chiko`
- პაროლი: `Password123`

ან შექმენით ახალი ანგარიში `/signup`-ზე.

პროდაქშენისთვის დააყენეთ `AUTH_SECRET` გარემოს ცვლადი (იხილეთ `.env.example`, გენერაცია: `openssl rand -base64 32`).

## პაროლის მოთხოვნები

რეგისტრაციისას პაროლი უნდა შეიცავდეს: მინიმუმ 8 სიმბოლოს, ერთ დიდ ასოს, ერთ პატარა ასოს და ერთ ციფრს. ვალიდაცია ხდება ორივე მხარეს — ფორმაში ცოცხლად ჩანს რომელი პირობაა შესრულებული, და სერვერზეც მოწმდება (`src/lib/password.ts`).

## სტეკი

- **Next.js 16** (App Router, Server Actions)
- **TypeScript**, **Tailwind CSS v4**, **framer-motion** (ანიმაციები/გვერდების გადასვლა)
- **SQLite** (`better-sqlite3`) — პირდაპირი SQL, ORM-ის გარეშე
- **JWT სესიები** (`jose`) httpOnly cookie-ში, პაროლები `bcryptjs`-ით ჰეშირებული

## რა არის აწყობილი

- რეგისტრაცია (პაროლის შეზღუდვებით) / შესვლა / გამოსვლა
- პოსტის დაწერა (სურათით), წაშლა, პასუხები (thread), **ციტატა-რეპოსტი (Quote Tweet)**
- Like, Retweet, Bookmark, პროფილზე პოსტის დამაგრება (Pin)
- გამოწერა/გაუქმება, **verified** ნიშანი ცალკეული ანგარიშებისთვის
- პროფილის გვერდი (პოსტები/პასუხები/მოწონებები) + რედაქტირება + ავატარი/header სურათის ატვირთვა
- მთავარი ფიდი: „თქვენთვის" და „გამოწერილები" — ანიმირებული ჩანართები
- შეტყობინებები (like, retweet, reply, follow, mention, quote) + კლიკადი @mention/#hashtag ბმულები
- **პირადი მიმოწერა (DM)** — საუბრების სია + ცალკეული საუბრის გვერდი
- ძებნა + ტრენდული ჰეშთეგები, ნახვების მთვლელი პოსტებზე
- მუქი/ღია თემა
- **ანიმაციები**: გვერდებს შორის fade/slide გადასვლა, სრიალა tab-ინდიკატორი, ჰარტის pop ეფექტი, ღილაკების tap-ანიმაცია, compose-მოდალის scale-გადასვლა, retweet/quote dropdown

## რაც შეგნებულად არაა შესული

Spaces ლაივ აუდიო, ვიდეო ატვირთვა/ტრანსქოდირება, ML-ალგორითმული ფიდი, სარეკლამო პლატფორმა — ეს კომპანიის მასშტაბის ინფრასტრუქტურაა.

## პროექტის სტრუქტურა

```
src/
  app/
    (app)/          # დაცული გვერდები (მთავარი, პროფილი, messages, ძებნა...)
    login/, signup/ # auth გვერდები
    api/upload/     # სურათების ატვირთვა (/public/uploads)
  components/
  lib/
    db.ts           # SQLite სქემა + seed მონაცემები
    queries.ts      # ყველა DB-ოპერაცია
    actions.ts      # Server Actions (auth, tweets, follows, DM...)
    auth.ts         # სესიის ლოგიკა (JWT cookie)
    password.ts     # პაროლის წესები
  proxy.ts          # მარშრუტების დაცვა (auth guard)
```

## თუ გაშვებისას პრობლემა შეგექმნათ

აპი `better-sqlite3`-ს იყენებს, რომელიც ნატიური მოდული — ინსტალაციისას პლატფორმისთვის შესაბამის ბინარს იწერს.

- **საჭიროა Node.js 20.9 ან უფრო ახალი** (`node -v` შესამოწმებლად). Next.js 16 ამაზე ნაკლებით არ იმუშავებს.
- თუ `npm install` შეცდომით დასრულდა `better-sqlite3`-ზე, სცადეთ: `npm install --build-from-source better-sqlite3`. Windows-ზე ამას სჭირდება [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) (C++ workload).
- სუფთა გადატვირთვა: წაშალეთ `node_modules`, `.next` და `data/app.db*`, შემდეგ თავიდან `npm install`.
- ბაზის „განულება" (დემო-მონაცემები თავიდან შეიქმნება): უბრალოდ წაშალეთ `data/app.db*` ფაილები.
